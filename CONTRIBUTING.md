# Como colaborar com o Markinho

Obrigado pelo interesse! Antes de tudo, leia isto:

## Código de terceiros não é aceito

O Markinho é um projeto pessoal com **um único autor**. **Pull requests (contribuições de código)
não são aceitos** e serão fechados sem revisão, mesmo que estejam corretos. O motivo: manter um
único autor permite, no futuro, oferecer o Markinho também sob outra licença (por exemplo, para uma
empresa que precise usá-lo num produto fechado), o que seria impossível com código de várias pessoas.

Isso não muda nada para quem usa: o Markinho continua livre sob a licença
[AGPL-3.0](LICENSE). Você pode estudar, modificar e distribuir a sua própria versão, seguindo a
licença — só não enviamos de volta para este repositório.

## O que é bem-vindo

- **Relatos de problema** (aba **Issues** > **New issue**): o que você fez, o que esperava e o que
  aconteceu. Ajuda muito anexar o texto de **Ajuda > Gerar relatório de erro…** (ele não contém o
  conteúdo dos seus documentos; confira antes de enviar).
- **Sugestões de funções**, também pelas Issues.
- **Arquivos de exemplo** que reproduzam o problema — **somente sem dados pessoais** e que você
  tenha direito de compartilhar.

## Falhas de segurança

**Não abra issue pública.** Veja [SEGURANCA.md](SEGURANCA.md) para relatar de forma privada.

## Sem garantia de resposta

É um projeto mantido quando possível: não há prazo garantido para respostas, correções ou novas
versões.
